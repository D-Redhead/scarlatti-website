# Restaurant Scarlatti – website

Statische site (HTML/CSS/JS, geen framework, geen build-stap) voor Restaurant Scarlatti, Stille Mare 4, Leiden.

- **Testsites:** Netlify (`scarlatti-testsite.netlify.app`, publiceert automatisch vanaf `main`) en GitHub Pages (workflow `.github/workflows/testserver.yml`). Beide staan op *noindex*.
- **Live (later):** Plesk. Upload de bestanden naar `httpdocs/`, zonder `_headers`, `netlify.toml`, `.github/` en de `.md`-bestanden. Zie `AANVULLEN.md`.
- **Ontwerp:** `DESIGN.md` · **Productinfo:** `PRODUCT.md` · **Nog in te vullen:** `AANVULLEN.md`
